# Suggested Notes

[Obsidian](https://obsidian.md) のサイドバーに、アクティブノートに関連するノートを表示するプラグインです。**日本語の Vault で実用になることを最優先に設計しています。**

タグ・リンク・バックリンク・ファイル名・(オプションで)本文語彙の共有をシグナルとする重み付きスコアで関連ノートを選びます。処理はすべてローカルで完結し、AI・外部通信・常駐処理はありません。

![アクティブノートの関連ノートとおすすめタグを表示するサイドバー](docs/screenshot.png)

[English README](./README.md)

## 特徴

- **日本語前提のトークナイザ** — スペースで区切られない日本語の本文・ファイル名からも語彙の一致を取り出します([詳細](#日本語対応の詳細))
- **メタデータ優先** — デフォルトでは本文を読まず、タグ・リンク・ファイル名だけで動作します。本文マッチングは任意で有効化
- **オフライン・非 AI** — 埋め込みも外部 API も使いません
- **軽量** — 転置インデックスで候補を絞ってからスコアリングします(Vault 全件スキャンなし)。モバイル対応
- **ノートに書き込まない** — プラグインの状態を frontmatter やタグに持ちません。ノートが変更されるのは、リンク追記・タグ追加のボタンを明示的に押したときだけです
- **UI は日本語 / 英語対応** — Obsidian の言語設定に従います

## 日本語対応の詳細

日本語はスペースで語が区切られないため、素朴な単語分割では語彙の一致が取れません。このプラグインでは次のように対応しています。

- 漢字の連続は「全体」と「2文字組」の両方をトークン化し、**Vault 内で単独の語として実在する2文字組だけを採用**します。これにより 機械学習 と 学習 は一致し、日本語 から生じる 本語 のような形態素をまたぐ断片は除外されます
- カタカナ複合語(リチウムバッテリー)も同じ方式で部分語(バッテリ)を取り出し、長音の表記揺れ(サーバー / サーバ)を正規化します
- 送り仮名混じりの語(打ち合わせ)やひらがなの語(ひらめき)は、同梱の TinySegmenter(約 25KB・オフライン・辞書不要)による分かち書きで抽出します(デフォルト有効)
- 全角 / 半角の揺れは NFKC 正規化で吸収します
- 組み込みの日本語ストップワードは、公開リスト(SlothLib・stopwords-iso)との照合と文法カテゴリによる審査を通った語だけで構成しています([方針](#組み込みストップワード))

## インストール

コミュニティプラグインストアには登録していません。以下のいずれかでインストールできます。

### BRAT 経由(推奨)

1. コミュニティプラグインストアから [BRAT](https://github.com/TfTHacker/obsidian42-brat) をインストール
2. BRAT の設定 → "Add Beta plugin" → `kogedango/suggested-notes-plugin` を入力
3. コミュニティプラグイン一覧で "Suggested Notes" を有効化

BRAT は新しいリリースが出ると自動更新します。

### 手動インストール

1. 最新の [Release](https://github.com/kogedango/suggested-notes-plugin/releases) から `main.js`, `manifest.json`(および `styles.css` があれば)をダウンロード
2. `<vault>/.obsidian/plugins/suggested-notes/` に配置
3. Obsidian を再読み込みし、コミュニティプラグイン一覧で "Suggested Notes" を有効化

## スコアリングの仕組み

アクティブノートごとに、転置インデックス(`tag → files`, `link → files`, `token → files`)で候補集合を絞ってからスコアリングします。各候補のスコアは共有シグナルの重み付き和です。

| シグナル | デフォルト重み | 補正 |
|---|---|---|
| 共有アウトリンク | 8 | リンクごとの IDF |
| 共有タグ | 5 | タグごとの IDF |
| 共有バックリンク | 4 | 共引用元の特異性(リンクの少ないノートからの共引用ほど強い証拠として扱う) |
| 共有タイトル語 | 3 | トークンごとの IDF |
| 共有 body トークン | 1.5 | トークンごとの IDF |

生スコアは候補ノートの `log(1 + アウトリンク数)` で除算し、MOC・インデックスノートが上位を独占するのを抑えます。表示スコアはクエリごとに正規化されます(最上位 = 100)。

フォルダの重みはデフォルト 0 です。同じフォルダのノートは「そこに置いたから」という理由で近いことが多く、上位に出すと本当に有用な提案を押し出すためです(設定で変更可能)。

### タイトル語マッチング

**メタデータのみ・デフォルトで有効。** ファイル名だけを読み、本文は読みません。ファイル名に共通の語を持つノート(「機械学習 基礎」と「機械学習 応用」など)が、IDF で重み付けされたスコアを得ます。トークナイザは本文用と同じですが分かち書きは使わないため、ひらがなだけのタイトルは拾えません(既知の制限)。「メモ」「日記」のような汎用語で候補が膨れないよう、Vault の 20% を超えるノートが持つタイトル語は新規候補の発見には使いません(発見済み候補のスコアには加算されます)。無効にしたい場合は重みを 0 にしてください。

### body トークンマッチング

**オプション機能・デフォルトで無効。** タグやリンクが張られていなくても、本文中の希少な語彙を共有していれば関連として拾います。本文を読むのはこの機能だけです。

- frontmatter・コードブロック・wikilink・ハッシュタグ・URL を除去してからトークン化
- 各ノートで `log(1+TF) × IDF` 上位 N 語(デフォルト 40)を保持し、共有語ごとに加点
- Vault の 40% 以上に出る語は自動除外

有効化すると全 `.md` を一度読んでインデックスを構築します(5,000 ノートで 10〜20 秒、非同期で UI はブロックしません)。その後はアクティブノートだけを開くたびに読み直し(最新の編集が即反映)、編集したノートは編集が落ち着き次第(約 2 秒)更新、Vault 全体の語彙統計は編集の約 1 分後に自動再構築されます(設定画面の Rebuild ボタンまたはコマンドで即時実行も可能)。

## 機能

- アクティブノートの関連ノートをサイドバーに一覧表示
- 行ホバーでスコア内訳、Cmd/Ctrl+ホバーでノート本文プレビュー
- 各行に**リンク追記ボタン**(アクティブノート末尾に `[[リンク]]` を追記。他のノートは変更しません)と**コピーボタン**
- タグ提案 — 結果に頻出するがアクティブノートに無いタグを表示。クリックで frontmatter に追加
- 除外設定: フォルダ / タグ / アウトリンク / body トークン([仕様](#除外設定の仕様))

## 設定

| 項目 | デフォルト | 備考 |
|---|---|---|
| Max results | 20 | |
| Shared outlinks weight | 8 | |
| Shared tags weight | 5 | |
| Shared backlinks weight | 4 | |
| Shared title words weight | 3 | メタデータのみ(ファイル名)。0 で無効化 |
| Enable body-token matching | off | ON で全ノート本文を読み込む。OFF はメタデータのみ |
| Body-token weight | 1.5 | 低めに保つ(1〜2) |
| Salient tokens per note | 40 | ノートあたりの保持語数 |
| Japanese word segmentation | on | TinySegmenter。日本語をあまり含まない Vault ではオフにするとインデックス作成が速くなります |
| Show scores | on | |
| Show shared reasons | on | 何を共有しているか表示 |
| Hide already-linked | off | |
| Excluded folders | — | 1 行 1 件。`Daily/` も `/Daily` も可 |
| Excluded tags | — | 1 行 1 件、先頭 `#` 不要 |
| Excluded links | — | 1 行 1 件 basename |
| Excluded body tokens | — | 自分の Vault 固有の頻出無意味語をここに |

設定名は英語 UI の表記です。日本語 UI では対応する日本語で表示されます。

### 除外設定の仕様

`excludedFolders` はノートを結果から完全に除外します。

`excludedTags` と `excludedLinks` は**そのシグナルを無視するだけ**で、除外タグを持つノートも他のシグナルで一致すれば結果に残ります。ノイズの多いタグの影響だけを消し、たまたまそのタグを持つ関連ノートは失わないための設計です。

特定のノート群を完全に隠したい場合は、フォルダに分けて `excludedFolders` を使ってください。

### 組み込みストップワード

body トークンマッチングの組み込みストップワードは [`src/data/stopwords.ts`](./src/data/stopwords.ts) にあります。全エントリは Vault に依存しない根拠カテゴリ(閉クラス文法・基礎語彙・活用断片・代名詞など)に属することを要件とし、特定の Vault やドメインでだけ頻出する語は含めません。自分の Vault 固有の頻出語は設定の **Excluded body tokens** に追加してください。組み込みリストへの提案は [GitHub の issue / PR](https://github.com/kogedango/suggested-notes-plugin) で受け付けています。
