# Suggested Notes

[Obsidian](https://obsidian.md) のサイドバーに、アクティブノートに関連するノートを表示するプラグインです。日本語と英語を同時に解析し、勉強ノートや技術ノートのような混在文にも対応します。

タグ・リンク・バックリンクと、タイトル・本文の内容語共有をシグナルとする重み付きスコアで関連ノートを選びます。処理はすべてローカルで完結し、AI・外部通信・常駐処理はありません。

![アクティブノートの関連ノートとおすすめタグを表示するサイドバー](docs/screenshot.png)

[English README](./README.md)

## 特徴

- **日英複合形態素解析** — Kuromoji/IPADIC と wink-nlp で内容語を抽出し、混在文の活用形を基本形へ統一します
- **内容照合をデフォルトで有効化** — タイトル語と本文重要語を重複のない一つの内容シグナルとして扱います。本文照合を無効にするとVault全体の本文索引を作らない軽量モードになります
- **オフライン・非 AI** — 埋め込みも外部 API も使いません
- **検索時の全件走査なし** — 転置インデックスで候補を絞ってからスコアリングします。モバイルは[v0.6.3プレリリースで検証中](docs/mobile-testing.md)です
- **プラグイン状態をノートに書き込まない** — ノートが変更されるのは、おすすめタグを明示的に追加したときだけです
- **UI は日本語 / 英語対応** — Obsidian の言語設定に従います

## 日英の形態素解析

ノート全体を一つの言語に分類せず、テキスト区間ごとに振り分けます。
日本語は Kuromoji/IPADIC、英語は wink-nlp のブラウザ向けモデルで解析します。
どちらも名詞・自立動詞・形容詞・副詞を採用し、活用形を基本形へ統一します
(`使った → 使う`、`uses → use`、`plugins → plugin`)。文法語は固定語彙の
ストップワードではなく、品詞に基づいて除外します。

Markdown構造、コード、URL、リンク、タグ、句読点、数値は語彙へ入れません。
タイトル・本文・ユーザー除外語は同じNFKC正規化と解析を共有します。一般辞書が
分割してしまうVault固有名は明示的に登録でき、正確な最長一致で1語として保護されます。
同じ語の別表記は `ツェッテルカステン|Zettelkasten` のように `|` でまとめられ、
すべて先頭表記へ正規化されます。ASCII表記は大文字小文字を区別せず、`AI` が
`RAIL` 内へ一致しないよう識別子境界を要求します。

連続する日本語名詞からは構成語と有効な複合語を保持します。空白なしで隣接する
英語識別子も同じ複合語へ参加するため、`機械学習`、`自然言語処理`、`API設計`
のような主題語を索引できます。`C++`のような記号入りVault固有語も、同じ記号表記で
登録すれば記号除去より前に保護されます。

## インストール

コミュニティプラグインストアには登録していません。以下のいずれかでインストールできます。

### BRAT 経由(推奨)

1. コミュニティプラグインストアから [BRAT](https://github.com/TfTHacker/obsidian42-brat) をインストール
2. BRAT の設定 → "Add Beta plugin" → `kogedango/suggested-notes-plugin` を入力
3. コミュニティプラグイン一覧で "Suggested Notes" を有効化

BRAT は新しいリリースが出ると自動更新します。

### 手動インストール

1. 最新の [Release](https://github.com/kogedango/suggested-notes-plugin/releases) から
   `main.js`, `manifest.json`（および `styles.css` があれば）をダウンロード。
   ライセンス表示は`main.js`にも埋め込まれています。読みやすい別ファイルとして
   `LICENSE`, `THIRD_PARTY_NOTICES.md`, `LICENSE-2.0.txt`, `NOTICE.md`も添付しています
2. `<vault>/.obsidian/plugins/suggested-notes/` に配置
3. Obsidian を再読み込みし、コミュニティプラグイン一覧で "Suggested Notes" を有効化

## スコアリングの仕組み

アクティブノートごとに、転置インデックス(`tag → files`, `link → files`, `token → files`)で候補集合を絞ってからスコアリングします。各候補のスコアは共有シグナルの重み付き和です。

| シグナル | デフォルト重み | 補正 |
|---|---|---|
| 共有アウトリンク | 8 | リンクごとの IDF |
| 共有タグ | 5 | タグごとの IDF |
| 共有バックリンク | 4 | 共引用元の特異性(リンクの少ないノートからの共引用ほど強い証拠として扱う) |
| このノートへの直接リンク | 6 | 固定値。候補からアクティブノートへの非対称リンク |
| タイトルの未リンク言及 | 8 | 固定値。候補タイトル全体がアクティブ本文に現れる |
| 共有内容語 | 1.5 | トークンごとの IDF |
| 同一フォルダ | 0 | 固定値。0より大きい場合だけ候補を追加 |

生スコアは候補ノートの `max(1, log(1 + アウトリンク数))` で除算し、MOC・インデックスノートが上位を独占するのを抑えます。表示スコアはクエリごとに正規化されます(最上位 = 100)。

フォルダの重みはデフォルト 0 です。同じフォルダのノートは「そこに置いたから」という理由で近いことが多く、上位に出すと本当に有用な提案を押し出すためです(設定で変更可能)。

### 内容語マッチング

**デフォルトで有効。** ノートの内容語集合は、タイトル語と本文重要語の和集合です。
タイトル語は本文の上位N語制限に埋もれず必ず保持され、同じ語がタイトルと本文の両方に
あっても1回だけ加点します。これにより、共有タイトル語を別シグナルにせず、
アクティブタイトルと候補本文（およびその逆）も照合できます。

- frontmatter・コードブロック・wikilink・ハッシュタグ・URL を除去してからトークン化
- 各ノートで `log(1+TF) × IDF` 上位 N 語(デフォルト 40)を保持し、共有語ごとに加点
- Vault の 40% を超えるノートに出る語は候補集合の拡張に使わない

初回はタイトルを一定件数ずつ解析し、全 `.md` の本文索引も非同期バッチで構築します。
次回からは保存済み索引を先に復元し、新規・変更ノートだけを解析します。アクティブノートは
開くたびに読み直し、編集したノートは編集が落ち着き次第更新します。文書頻度が変わった語を
持つノートだけを再選定し、連続するキャッシュ保存もまとめます。設定画面のRebuildボタンまたは
コマンドは全件を読み直す修復処理です。本文照合を無効にすると、Vault全体の本文索引を
作らない軽量モードになります。

### タイトルの未リンク言及

アクティブノート本文に、候補ノートのファイル名全体が通常テキストとして現れるかを
確認します。単語共有とは別の構造的シグナルで、これだけでも候補を発見できます。

- 既存のwikilinkとMarkdownリンクは数えない
- frontmatter・コード・URL・タグ・画像リンクは数えない
- NFKC正規化を行い、英字は大文字小文字を区別しない
- 1文字タイトルと、同じbasenameを持つ曖昧な複数ノートは対象外
- 同じ位置で複数タイトルが一致するときは最長タイトルを採用
- 読む本文はアクティブノートだけで、Vault全体の本文索引は不要

重みを0にすると、アクティブ本文の未リンク言及走査も無効になります。

## 機能

- アクティブノートの関連ノートをサイドバーに一覧表示
- 行ホバーまたはスコアのタップで内訳を表示。Cmd/Ctrl+ホバーでノート本文プレビュー
- デスクトップでは行ホバー時のボタン、モバイルでは行の長押しでリンクをコピー。コピーではノートを変更しません
- タグ提案 — 結果に頻出するがアクティブノートに無いタグを表示。クリックで frontmatter に追加
- 除外設定: フォルダ / タグ / アウトリンク / 内容語([仕様](#除外設定の仕様))

## 設定

| 項目 | デフォルト | 備考 |
|---|---|---|
| Max results | 20 | |
| Shared outlinks weight | 8 | |
| Shared tags weight | 5 | |
| Shared backlinks weight | 4 | |
| Direct link weight | 6 | 候補からアクティブノートへの非対称リンク |
| Unlinked title mention weight | 8 | アクティブ本文に候補タイトル全体が現れる場合 |
| Same folder weight | 0 | 0より大きい場合だけ候補へ追加 |
| Shared content words weight | 1.5 | タイトルと本文にある同じ語は1回だけ加点 |
| Enable body-token matching | on | OFF はVault全体の本文索引を作らない |
| Salient tokens per note | 40 | ノートあたりの保持語数 |
| Vault固有語 | — | 1行1語または `代表語|別表記`。最長一致を1語として保護 |
| Show scores | on | |
| Show shared reasons | on | 何を共有しているか表示 |
| Hide already-linked | off | |
| Excluded folders | — | 1 行 1 件。`Daily/` も `/Daily` も可 |
| Excluded tags | — | 1 行 1 件、先頭 `#` 不要 |
| Excluded links | — | 1 行 1 件 basename |
| Excluded content words | — | タイトルと本文の両方に適用 |

設定名は英語 UI の表記です。日本語 UI では対応する日本語で表示されます。

### 除外設定の仕様

`excludedFolders` はノートを結果から完全に除外します。

`excludedTags` と `excludedLinks` は**そのシグナルを無視するだけ**で、除外タグを持つノートも他のシグナルで一致すれば結果に残ります。ノイズの多いタグの影響だけを消し、たまたまそのタグを持つ関連ノートは失わないための設計です。

特定のノート群を完全に隠したい場合は、フォルダに分けて `excludedFolders` を使ってください。

### 語彙の除外

組み込みの日本語・英語ストップワードリストはありません。文法語は品詞で除外し、
一般的すぎる内容語はdfで抑制し、Vault固有のノイズは **Excluded content words** へ
明示的に登録します。
