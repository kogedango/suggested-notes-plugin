# v0.6.5（プレリリース）

モバイルの長押しコピー表示を整理した検証版。

## コピー操作

- コピー成功後の行フラッシュとチェック付き吹き出しを廃止し、Obsidian 標準の
  通知だけで完了を伝える。
- 長押し成立中の表示から独自のアクセント色、左線、アニメーションを取り除く。
- 押下中は現在のテーマが定義するナビゲーション項目のホバー色と角丸を使用する。
- 長押し判定、スクロール時のキャンセル、長押し後の合成タップ抑止、WebKit 向けの
  touchend 内クリップボード書き込みは従来どおり維持する。

## 検証状況

- 自動テスト、型検査、製品ビルド、リリース資産と第三者ライセンスの検証を実施。
- iOS/iPadOS と Android の実機確認は未完了のため、引き続きプレリリース扱いとする。
