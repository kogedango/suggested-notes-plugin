# v0.6.1（プレリリース）

モバイルで関連ノート一覧を確認・操作しやすくするUI改善版。

## サイドバー

- ビュー名を「おすすめノート」から、プラグインを識別しやすい「Suggested Notes」へ変更。
- 同じサイドバービューが重複して開いている場合に、余分なビューを整理。
- スコアをタップまたはキーボード操作すると、スコア内訳を表示。
- スコア表示の外観はv0.6.0と同じコンパクトなチップを維持。
- 行ごとの操作をリンクコピーだけに整理。
- デスクトップでは行ホバー時、モバイルでは常時コピーボタンを表示。
- コピー成功時に短時間チェックアイコンを表示。

## モバイル検証

- v0.6.0の基本動作はiPhone 13で確認済み。
- v0.6.1では今回変更したスコア内訳とリンクコピーを中心に再検証する。
- Androidと詳細な負荷・キャッシュ検証は未実施のため、引き続きプレリリース扱いとする。
