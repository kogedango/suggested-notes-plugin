# v0.6.4（プレリリース）

v0.6.3 の長押しコピー改善に加え、モバイル検証前にメモリ、キャッシュ I/O、
初期化処理を見直した検証版。

## メモリと初期化

- 日本語辞書の圧縮データを展開後も保持していた経路をなくし、一時バッファを早く
  解放する。
- 辞書ロード中の不要な配列コピーを避け、展開済みバッファを辞書生成時に順次消費
  する。
- キャッシュ復元とインデックス保存で大きな中間オブジェクトが重なりにくい処理へ
  変更する。
- 形態素解析キャッシュを専用ファイルへ分離し、設定データの読み書きに巨大な
  キャッシュを毎回含めない。

## I/O と保守性

- 内容が変わっていないキャッシュは起動時に書き戻さない。
- キャッシュ保存をストリーミング化し、一時的な文字列・配列のピークを抑える。
- 設定変更の連続保存を短時間まとめ、不要なディスク書き込みを減らす。
- 時間・バイナリ定数、IDF 計算、協調 yield、debounce 処理を共通化し、重複と
  マジックナンバーを整理する。

## コピー操作

- 行の長押し解除時にリンクを直接コピーし、行の点灯、チェック付き表示、通知で
  成否を明確にする。
- WebKit のユーザー操作制約に合わせてクリップボード書き込みを touchend 内で
  実行する。
- 長押し後の合成タップ、スクロール開始、スコア操作との競合を抑える。

## 検証状況

- 自動テスト、型検査、製品ビルド、リリース資産と第三者ライセンスの検証を実施。
- v0.6.1までの基本動作はiPhone 13で確認済み。
- v0.6.4では長押しコピー、2回目以降のキャッシュ復元、初回インデックス中の
  メモリ警告・フリーズを重点的に確認する。
- Androidと詳細な負荷・バッテリー検証は未実施のため、引き続きプレリリース扱い
  とする。
