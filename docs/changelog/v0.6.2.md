# v0.6.2（プレリリース）

モバイルの関連ノート一覧から常設コピーボタンを撤去し、表示領域と操作を整理した
検証版。

## モバイル操作

- 行の通常タップでノートを開く。
- スコアの通常タップでスコア内訳を表示・非表示。
- 行を約0.5秒長押しすると行がハイライトし、指を離した時点でリンクをクリップ
  ボードにコピー。メニューは挟まない。
- ハイライトは指の下でも見える位置に出す手掛かり。完了は通知で伝える。指を離す
  までに指を動かせばキャンセルできる。
- クリップボードへの書き込みは touchend で行う。WebKit はユーザー操作を伴わない
  タイマー内からのクリップボード書き込みを拒否するため。
- 書き込みに失敗した場合は無音にせず、失敗の通知を出す。
- 長押しから指を離したときに合成されるタップは無視し、ノートを開かない。以降の
  通常タップは即座に有効。
- スコアの長押しではコピーしない。
- 指を動かしてスクロールを始めた場合は、長押し判定をキャンセル。

## デスクトップ

- 従来どおり、行ホバー時にコピーボタンを表示。

## 検証状況

- v0.6.1までの基本動作はiPhone 13で確認済み。
- v0.6.2では長押し、通常タップ、スコアタップ、縦スクロールの競合を再検証する。
- Androidと詳細な負荷・キャッシュ検証は未実施のため、引き続きプレリリース扱いとする。
