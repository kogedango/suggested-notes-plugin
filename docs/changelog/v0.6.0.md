# v0.6.0（プレリリース）

固定ストップワードと誤分割ごとの補修規則を廃止し、日本語・英語の品詞と
基本形に基づく語彙抽出へ再設計したバージョン。

## 形態素解析

- 日本語は Kuromoji + IPADIC を使用。
- 英語は wink-nlp + English Light Web Model を使用。
- ノート全体ではなくテキスト区間ごとに日英を振り分け、混在文を解析。
- 名詞、自立動詞、形容詞、副詞を採用し、文法語は品詞で除外。
- 活用形を基本形へ統一（`使った → 使う`、`uses → use`）。
- 英語名詞の単複を統一（`plugins → plugin`）。
- 辞書未知語・固有名詞・技術識別子は、文法語である根拠がなければ保持。
- 連続する日本語名詞から、構成語、長さ2・3の複合語、4形態素以上の最大列を生成。
  接頭詞・接尾辞の境界を保ち、数詞・助数詞・空白・文法語をまたいで連結しない。
- 空白なしで隣接する英語名詞・固有名詞・識別子やVault固有語を日本語名詞列へ参加させ、
  `API設計`、`Web開発`、`機械学習モデル`のような混在複合語を保持。

## Vault固有語

- 1行につき1語または1同義語グループを設定。
- `代表語|別表記|別表記`の形式で同義表記をグループ化し、すべてを先頭の代表語へ正規化。
- 複数行が同じ別表記を共有する場合は、同じ等価グループとして推移的に統合。
- 通常語はNFKC正規化後の正確な表層形へ一致。`C++`など記号を含む登録語は、
  同じ記号表記へ記号除去前に一致して保護。
- 同じ位置では最長一致を優先し、一つのトークンとして保護。
- ASCII英字は大小文字を同一視。英数字から始まる／終わる語は識別子境界を要求し、
  別の英単語や識別子内部への部分一致を防止。
- タイトルと本文へ同じ規則を適用。

## 起動と索引

- タグ、リンク、バックリンクのメタデータ結果を解析器初期化前から表示。
- 日本語・英語解析器は各一インスタンスをタイトルと本文で共有。
- タイトル索引を一定件数ずつ構築し、イベントループへ制御を返す。
- タイトル語と本文重要語を一つの内容語集合として照合し、両方にある同じ語は1回だけ加点。
- タイトル語は本文のtop-N制限に埋もれず必ず保持。
- 共有タイトル語を独立シグナルとする重み設定を廃止。
- 本文照合は新規設定でデフォルトON。既存ユーザーが保存済みのOFF設定は維持。
- 本文照合をOFFにした場合は、Vault全体の本文索引を作らない軽量モードとして動作。
- 本文索引は完成した世代だけを原子的に反映。

## タイトルの未リンク言及

- アクティブ本文に候補ノートのタイトル全体が通常テキストとして現れる場合、独立した候補・加点シグナルとして扱う。
- wikilink、Markdownリンク、frontmatter、コード、URL、タグ、画像リンク内は対象外。
- NFKC正規化と英字の大小文字統一を適用。
- 1文字タイトル、同一basenameが複数ある曖昧なタイトルは対象外。
- 同じ位置では最長タイトルを優先。
- タイトル照合索引は常設し、ノート作成・削除・名前変更時だけ差分更新。
- 本文索引がOFFでもアクティブノート1件だけを読み取って動作し、重み0で走査を停止可能。

## 削除

- TinySegmenter。
- 漢字・カタカナのscript-run、2-gram、standalone判定。
- 促音便、い音便、形容詞過去形の推測補修。
- repair vocabularyと補修用df世代。
- 組み込み日本語・英語ストップワード。
- 旧解析方式との切り替えトグル。

## その他

- 本番依存の処理はすべてローカルで完結し、外部通信を行わない。
- Kuromoji辞書と英語モデルを`main.js`へ同梱するため、配布サイズは増加する。
- 本体・Kuromoji/IPADIC・MIT依存のライセンスとNOTICEを`main.js`先頭へ埋め込み、
  BRAT経由でも表示を配布。production buildは、バンドルされた依存と表示一覧の
  不一致を検出して失敗する。
- タイトル・本文の形態素解析結果を永続化し、次回起動では保存済み索引を先に表示して、
  新規・変更ノートだけを差分解析する。編集・削除・名前変更時のVault全体の語彙統計も、
  全ノートを読み直さずに更新する。
- 通常編集ではdfが変化した語を持つノートだけ本文重要語を再選定し、無関係なノートは再計算しない。
- 連続編集時の永続キャッシュ書き込みをまとめ、全キャッシュJSONの書き込み増幅を抑制。
- Kuromoji辞書の解凍結果をTypedArrayからコピーせず参照し、初期化時の一時メモリを削減。
- iOS 16.4未満でも構文エラーにならないよう、正規表現のlookbehind依存を除去した。
- 詳細な現行仕様は `docs/architecture.md`、モバイル検証状況は
  `docs/mobile-testing.md` を参照。
