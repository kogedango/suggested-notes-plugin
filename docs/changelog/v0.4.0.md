# v0.4.0 (2026-07-06)

日本語Vault向けの機能強化と、公開リリースに向けた準備を行ったバージョン。

## 新機能

- **タイトルトークン・シグナル追加**: ファイル名（basename）に含まれる共通語をIDF重み付きでスコアリングに反映。`bodyTokenEnabled`（本文トークン照合）がOFFでも動作する、メタデータのみの標準機能。汎用的すぎる単語（メモ、日記など、Vaultの20%超に出現するもの）は候補拡張の対象から除外し、候補ブロートを防止。
- **共有バックリンクをソースの特異性で重み付け**: MOC/インデックスノートからの被リンクより、特定テーマに絞られたノートからの被リンクをより強いシグナルとして評価（`backlinkWeight / log(1 + sourceOutlinkCount)`）。
- **直接リンクのスコアリングを新設**: 候補ノートが対象ノートにリンクしているが、対象ノートからはまだリンクしていない場合を`directLinkWeight`（デフォルト6）として明示的にスコア化。サイドバーに「このノートへのリンク」として表示。
- **候補生成の拡張**:
  - 被リンク数が少ない（outlinkCount ≤ 20）フォーカスされたハブノートを経由した候補拡張
  - 同一フォルダのノートを候補に含める機能（`folderWeight > 0`のとき、デフォルトはOFF）
- **本文トークン除外設定を追加**: 「コメント」「結果」など繰り返し出る見出し語を`excludedBodyTokens`で除外可能に（タグ・リンク除外と同様、リビルド不要）。
- **ノート末尾へのリンク追加ボタン**: サイドバーの各候補行に、`vault.process` + `generateMarkdownLink`で対象ノート末尾にリンクを追記するボタンを追加（リンク形式設定を尊重、既存ノートは変更しない）。

## 日本語対応の改善

- **セグメンター（tiny-segmenter）をデフォルトON化**: 1,262ノートのVaultでのCPUベンチマークをクリア（フルコーパス再構築2.15秒、クエリp95 4.7ms）。実験的opt-inから標準機能へ昇格。
- **漢字ラン内2-gramの`standalone`ゲート**: コーパス全体で単独語として出現する2-gramのみを採用し、形態素をまたぐノイズ（「日本語」から「本語」など）を除去。実質語（「機械学習」から「機械」「学習」）は保持。
- **カタカナ複合語のサブワード分割**: 「リチウムバッテリー」のような連続カタカナ語から、standaloneセットでゲートされたサブワード（「バッテリ」など）を抽出。3文字未満のサブワードはクロス形態素ノイズとして除外。
- **ストップワードの一般化・整理**: SlothLib / stopwords-iso/ja の公開リストと突合し、意味のある一般名詞を除外せずに38語を追加。`src/data/stopwords.ts`に根拠カテゴリ別で分離し、Vault固有の16語を監査除去。閉じたクラスの漢字ゲート（`KANJI_STOPWORDS`）も追加。
- **トークナイザーのTF/リークバグ修正**: 2文字漢字ランのTFが二重カウントされていた問題、本文中の裸URL処理、タグ除去の誤動作（`#1`のような英数字タグは残し、`#2024振り返り`のような数字始まりタグのみ除去）を修正。
- **混在セグメント用ストップワード追加**（`JA_MIXED_STOPWORDS`、104語）: 「食べ」「起き」「読ん」のような活用の断片を除去しつつ、「学び」「問い」「動き」のような名詞化された語は保持。
