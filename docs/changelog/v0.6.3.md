# v0.6.3（プレリリース）

v0.6.2 のモバイル長押しコピーを、メニュー経由から直接コピーに置き換えた検証版。

## モバイル操作

- 行の通常タップでノートを開く。
- スコアの通常タップでスコア内訳を表示・非表示。
- 行を約0.5秒長押しすると行がハイライトし、指を離した時点でリンクをクリップ
  ボードにコピー。v0.6.2 のメニューは挟まない。
- ハイライトは指の下でも見える位置に出す手掛かり。指を離してコピーに成功すると、
  行が短く点灯し、チェック付きの「コピーしました」表示と通知で完了を伝える。指を
  離すまでに指を動かせばキャンセルできる。
- クリップボードへの書き込みは touchend で行う。WebKit はユーザー操作を伴わない
  タイマー内からのクリップボード書き込みを拒否するため。
- 書き込みに失敗した場合は無音にせず、失敗の通知を出す。
- 長押しから指を離したときに合成されるタップは無視し、ノートを開かない。以降の
  通常タップは即座に有効。v0.6.2 では長押し後1秒間その行のタップが効かなかった。
- スコアの長押しではコピーしない。
- 指を動かしてスクロールを始めた場合は、長押し判定をキャンセル。

## デスクトップ

- 従来どおり、行ホバー時にコピーボタンを表示。
- コピー先のファイルが解決できなかった場合、成功扱いにしない。

## 検証状況

- v0.6.1までの基本動作はiPhone 13で確認済み。
- v0.6.2の長押しメニューは実機未検証のまま置き換えたため、検証対象は v0.6.3 の
  挙動のみとする。
- v0.6.3では長押しでコピーしたリンクが実際にペーストできるかを最初に確認する。
  WebKit のクリップボード制限を回避できているかがこの版の可否を決める。
- あわせて通常タップ、スコアタップ、縦スクロールとの競合を再検証する。
- Androidと詳細な負荷・キャッシュ検証は未実施のため、引き続きプレリリース扱いとする。
